# Tableau de bord

## Vue d'ensemble

Le tableau de bord est la page d'accueil de Wedy RH. Il offre une vue consolidée en temps réel de l'ensemble de vos indicateurs RH clés.

**URL :** `/app`  
**Accès :** Admin, RH Manager

---

## Cartes statistiques

En haut de page, 4 cartes affichent les KPIs essentiels :

| Carte | Description |
|---|---|
| **Effectif total** | Nombre d'employés actifs. Cliquez pour accéder à la liste complète. |
| **Congés en cours** | Absences validées aujourd'hui. Cliquez pour voir le détail. |
| **Documents ce mois** | Nombre de documents générés dans le mois courant. |
| **Stagiaires actifs** | Nombre de stagiaires dont le stage est en cours. |

---

## Flux d'activité récente

Le panneau en bas affiche les 10 dernières actions sur la plateforme :
- Création / modification d'un dossier employé
- Document généré ou téléchargé
- Demande de congé soumise ou approuvée
- Nouvelle candidature reçue

Cliquez sur n'importe quelle entrée pour accéder directement à l'élément concerné.

---

## Alertes et rappels

Le tableau de bord signale automatiquement :
- **Contrats expirant dans 30 jours** — avec lien vers le dossier employé
- **Fins de stage à venir** — avec bouton de génération d'attestation
- **Demandes de congé en attente** — avec raccourci d'approbation rapide

---

## Astuces

1. Le bouton **Actualiser** (↻) en haut à droite force un rechargement des données sans rafraîchir la page.
2. Les cartes statistiques sont cliquables — elles redirigent vers la page filtrée correspondante.
3. Le tableau de bord se met à jour automatiquement toutes les 5 minutes en arrière-plan.
